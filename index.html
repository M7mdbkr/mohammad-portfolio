  1. Samba Active Directory on Ubuntu Server: users, groups, shares‏Samba Active Directory على Ubuntu Server: مستخدمون ومجموعات ومجلدات مشتركة
  2. Group Policy pushed down to every Windows clientسياسات المجموعة تُطبَّق على كل جهاز ويندوز
  3. Default Deny wraps the domainسياسة «الرفض الافتراضي» تحيط بالنطاق

Case 04 · LAB.LOCALالمشروع 04 · LAB.LOCALProblem ↑ solutionالمشكلة ↑ الحل
The problem
المشكلة

I wanted to run a few Windows PCs the way a company does: central users, policies and internet limits. Windows Server licences cost money I didn't want to spend on a lab.

أردت إدارة عدة أجهزة ويندوز كما تفعل الشركات: مستخدمون مركزيون وسياسات وحدود للإنترنت. تراخيص Windows Server مكلفة، ولم أرد دفعها على مختبر.

What I built
ما بنيته

A domain called LAB.LOCAL on Ubuntu Server with Samba as the Active Directory domain controller: one server and two client PCs, one admin account and four client users (c1 to c4), shares, groups and Group Policy.

نطاق اسمه LAB.LOCAL على Ubuntu Server مع Samba كوحدة تحكم Active Directory: خادم واحد وجهازا عميل، وحساب مدير وأربعة مستخدمين (c1 إلى c4)، ومجلدات مشتركة ومجموعات وسياسات مجموعة.

How I solved it
كيف حللتها
  • Samba AD provides domain-control functions for this lab using an open-source server stack.‏Samba AD يوفّر وظائف التحكم بالنطاق لهذا المختبر باستخدام أدوات خادم مفتوحة المصدر.
  • Default Deny: nothing is allowed unless a policy says so.الرفض الافتراضي: لا شيء مسموح ما لم تسمح به سياسة.
  • Squid proxy plus a GPO that forces every client through it, enforcing a 120 MB daily internet quota per user.بروكسي Squid مع سياسة GPO تُلزم كل جهاز بالمرور عبره، لفرض حصة إنترنت يومية 120 ميجابايت لكل مستخدم.
  • I cleaned up the domain by disabling the old test users, and documented everything in a private GitHub repo.نظّفت النطاق بتعطيل مستخدمي الاختبار القدامى، ووثّقت كل شيء في مستودع GitHub خاص.
Where it is now
أين وصل الآن

A working domain with Group Policy running on real hardware. An administration dashboard is part of the future development plan.

نطاق يعمل مع سياسات المجموعة على أجهزة حقيقية. لوحة الإدارة ضمن خطة التطوير المستقبلية.
