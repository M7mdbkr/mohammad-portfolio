# Figma-ready portfolio report

Nine 1600×1000 SVG frames for importing into Figma. Import the SVGs in filename order to create a polished case-study report.

The report uses an original editorial visual system: warm paper, ink, coral, teal, and restrained mono labels. Project claims are limited to locally verified evidence; runtime data, credentials, private notes, generated media, and third-party clones are excluded.
